# Equipo de Marketing · KINGFA

Directorio del equipo de Marketing de Kingfa USA (región México), organizado por región: Frontera, Bajío, Norte y Centro.

- `index.html`: página principal con las regiones y el liderazgo
- `region.html?id=<region>`: contactos de cada región
- `data.js`: datos del equipo (aquí se agregan o editan integrantes y regiones)
- `MX_Sales_Group_Members_Detailed.json`: datos originales del equipo con el campo `region`


Se publica con GitHub Pages desde la rama `main`.
